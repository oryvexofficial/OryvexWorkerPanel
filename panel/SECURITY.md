# Security Policy

## Supported Versions

Security updates are provided for the latest release.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through **GitHub Security Advisories** on this repository (Security tab, then "Report a vulnerability"). Please do not open a public issue for security problems. All reports are evaluated promptly.
